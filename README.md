# 交流イベントの紹介ページ ― GitHub演習用

これは架空のイベントです。共同作業を学びます。
実在の参加者、連絡先、申込みフォーム、決済機能はありません。

## イベントの基準情報
- 開始：13:00
- 参加費：無料
- 会場：交流室A

仕様の確認先は `docs/event-spec.md`、FAQの作業メモは `docs/faq.md` です。
`docs/schedule.txt` は競合解消の専用練習ファイルです。

## 手元で表示する
1. このフォルダにある `index.html` を、OSのファイル管理画面からブラウザで開く。
2. アドレスが `file://` で始まることを確認する。
3. 編集したら保存し、ブラウザを再読み込みする。
4. 変更箇所だけでなく、開始時刻・参加費・会場も確認する。

ブラウザ以外の実行環境や追加パッケージは不要です。
HTMLとCSSのみで、JavaScriptや外部通信を含みません。
GitHubのCode画面にファイルがあることと、Webサイトとして公開されていることは別です。

## チームで変更する
`CONTRIBUTING.md` を読み、目的と完了条件をIssueに書いてからブランチを作る。
PRには変更内容、確認方法、未確認事項を記載する。
本番・研究・業務の資料や、本物の個人情報・認証情報は追加しない。
不明点は案内担当へ確認します。

配布者は、一般公開前に教材の利用条件・ライセンス方針を決めて記載してください。
